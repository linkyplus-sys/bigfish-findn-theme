# 大肥鱼深海蓝釉输入法

V2.2 用两层浪纹、玻璃键帽和鲸尾菜单融合深海视觉。回车常态亮度接近普通键，九键数字和字母分层排布。外屏九键及按下态已在 Find N 的百度输入法定制版 8.5.301.551 实测。

1. 打开输入法「皮肤设置 → 自定义」，选择 `大肥鱼-深海蓝釉-键盘背景.png`，使用默认裁切。按键选第 5 项，滑块约三分之一，字体选第 4 项白色字形。保存本机 DIY BDA。
2. 在 Windows PowerShell 中执行下方命令。构建需要 Node.js 和 FFmpeg。`$diyBda` 指向本机生成的 BDA，`$soundTemplate` 指向本机兼容的音效模板，其中含 `port/soundConfig` 和 `land/soundConfig`。
3. 在「皮肤设置 → 我的皮肤 → 我的制作」启用产出的 V2.2 皮肤。保留源 DIY 皮肤便于恢复。

```powershell
& .\生成深海工具栏.ps1 -Source $diyBda
& .\生成深海玻璃版.ps1
& .\生成玻璃按键音版.ps1 -Template $soundTemplate
& .\生成深海玻璃版.ps1 -KeycapsOnly `
    -Source '.\大肥鱼-深海蓝釉-V2.1-玻璃音.bda' `
    -Output '.\大肥鱼-深海蓝釉-V2.2-玻璃音.bda'
```

如本机没有音效模板，可以用 V2.1 皮肤作为 `-KeycapsOnly` 的输入，得到保留原生按键声音的 V2.2 键帽。
