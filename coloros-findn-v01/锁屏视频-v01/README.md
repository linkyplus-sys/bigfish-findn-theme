# Find N 动态锁屏与静态桌面

壁纸组件 v0.6 根据屏幕比例在外屏和内屏之间切换。桌面显示蓝釉静态图，锁屏播放对应的静音视频。

| 屏幕 | 视频 | 桌面 |
| --- | --- | --- |
| 外屏 | [新版静音成片，1440 × 2560](<应用/assets/cover.mp4>) | [深海蓝釉桌面原图](<../深海桌面-v04/深海蓝釉-外屏-988x1972.png>) |
| 内屏 | [静音成片，1440 × 1344](<应用/assets/inner.mp4>) | [深海蓝釉桌面原图](<../深海桌面-v04/深海蓝釉-内屏-1920x1792.png>) |

```powershell
& '.\coloros-findn-v01\锁屏视频-v01\应用\构建应用.ps1' -ToolRoot 'C:\android-kit'
```

安装输出 `bigfish-lock-video-v01.apk` 后，在应用的预览界面应用壁纸。已有安装可通过 `-Keystore` 指定原有签名。设置后分别在折叠和展开状态检查锁屏播放与解锁后的静态桌面。[新版外屏实拍](<验收/外屏新版-锁屏与解锁.png>)
