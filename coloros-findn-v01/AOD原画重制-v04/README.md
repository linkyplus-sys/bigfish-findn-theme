# 蓝鲸娘 AOD v04

沿用原画配色，全程睁眼。身体绕腰部左右摆动约 ±2.55°、横移约 ±7.5 像素。长发横向位移上限从 13.5 增至 24 像素，两侧发束错开摆动。呆毛根部和头饰跟随头部，只有末端独立摆动。以上以 512 × 512 的动画母片计。

[手机 GIF](./交付/蓝鲸娘AOD-v04-FindN.gif)为 320 × 320，20 fps，120 帧，6 秒循环。[预览视频](./交付/蓝鲸娘AOD-v04-预览.mp4)。

Find N 外屏已通过「图文组合」应用。实际进入息屏状态后采集了不同动作帧。

如需重建，在 PowerShell 中先运行 Node.js 动画脚本并传入 FFmpeg 路径，再导出手机 GIF。

    node ./制作原画微动.mjs (Get-Command ffmpeg.exe).Source
    ./导出AOD.ps1
