# Find N 控制中心 · 深海图稿 v01

[外屏浅深预览](<外屏浅深预览.png>) · [全量图鉴](<全量图鉴.png>) · [可翻页预览](<控制中心总览.html>) · [SVG 文件与开关对应表](<图标清单.json>)

WLAN 用海面声呐弧和水滴，移动数据用反向水流箭头，飞行模式把尾翼收成一片鲸尾。静音、省电和手电筒把鲸尾融进铃身、能量图形和筒身。其余功能优先保留小尺寸下容易分辨的轮廓。

| 图稿范围 | 款数 | 核对依据 |
| --- | ---: | --- |
| 现用开关 | 23 | Find N 上的 `sysui_qs_tiles` |
| 固件候选 | 30 | `SystemUI.apk` 的手机默认、库存和附加开关；含地区或功能条件下的入口 |
| 应用开关 | 14 | 设备包管理器额外查询到的快捷设置服务 |
| 面板控件 | 16 | 设置、亮度、音量、编辑和播放等 |

对应表已核对 53 个固件候选入口及 29 个已登记服务。功能相同的三个服务入口复用相应主图。手电筒、静音、录屏另有一枚状态变体，共 86 个单色 SVG。HTML 预览可切换常态、强调和不可用，外屏面板可按页码翻看现用开关。

审稿面板的底色用于比较图形和对比度，真机着色由 ColorOS 控制。手电筒的开关和切换动画已在外屏验收。部分应用候选的原始资源来自各自 APK。 [控制中心覆盖包](<../覆盖包-v01/README.md>)
